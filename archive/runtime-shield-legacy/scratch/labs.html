Lab 1: Workspace Escape (Path Traversal)

Attempt to escape the sandbox workspace directory. This attack leverages path traversal (../../) to read sensitive system configuration files (like /etc/passwd or .env) located outside the authorized experiment zone.

Shield Mitigation: Layer 3 Policy Firewall scans tool path arguments in real-time, matching directory traversal patterns and absolute path escape routes, blocking the tool call before any disk read operations can execute.
